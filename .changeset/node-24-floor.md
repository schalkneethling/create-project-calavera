The CLI and the MCP server now require Node.js `^24.11.0 || >=26.0.0`. Node.js 22 is no longer supported, although Vite+ 1.0.0 still supports Node.js 22.18 and later. On Node.js 22, both print the required range and exit with a non-zero code. Upgrade to Node.js 24.11 or later before updating Calavera.
